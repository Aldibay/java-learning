# «КІТАПХАНА» — Java + PostgreSQL + JDBC + CRUD

**Тақырып:** №1. Кітапхана (авторлар, кітаптар, оқырмандар, кітап беру).  
**Форматы:** IntelliJ IDEA-ға арналған Java 17 / Maven консольдік жобасы.  
**Қажетті құралдар:** JDK 17+, IntelliJ IDEA, PostgreSQL сервері, DataGrip немесе pgAdmin (қосымша).

> **Назар аударыңыз:** тапсырманың бастапқы құжатында MySQL Connector/J міндетті деп көрсетілген. Бұл нұсқада пайдаланушының талабы бойынша **PostgreSQL және pgJDBC** қолданылған. Егер оқытушы тек MySQL қабылдайтын болса, бұл өзгерісті оқытушымен келісу қажет.

## 1. PostgreSQL деректер қорын дайындау (DataGrip)

1. PostgreSQL серверін іске қосыңыз. Әдетте жергілікті сервер `localhost:5432`, пайдаланушы `postgres` болады.
2. DataGrip → **+ → Data Source → PostgreSQL**. `Host=localhost`, `Port=5432`, `User=postgres`, `Password=өзіңіздің PostgreSQL құпиясөзіңіз` деп толтырыңыз. Бастапқы қосылым үшін `Database=postgres` көрсетіңіз; **Test Connection** басыңыз (қажет болса DataGrip драйверді жүктеуді ұсынады).
3. `postgres` деректер қорына қосылған SQL Console-да **бір рет қана** мына сұранысты орындаңыз (немесе `database/01_create_database.sql` файлын іске қосыңыз):
   ```sql
   CREATE DATABASE library_db;
   ```
   Егер база бұрыннан бар болса, бұл қадамды өткізіп жіберіңіз.
4. DataGrip ішіндегі қосылымның **Database** өрісін `library_db` деп өзгертіңіз (немесе оған жеке қосылым жасаңыз). SQL Console-да ағымдағы деректер қоры дұрыс екенін тексеріңіз:
   ```sql
   SELECT current_database();
   ```
   Нәтиже `library_db` болуы керек.
5. Осы `library_db` қосылымында **`database/library_db.sql`** файлын толық орындаңыз. Скрипт 4 байланысты кестені, индекстерді және бастапқы мысал жазбаларды жасайды. **`library_db.sql` файлын `postgres` базасында орындамаңыз!**
6. Деректерді тексеру:
   ```sql
   SELECT * FROM authors;
   SELECT * FROM readers;
   SELECT * FROM books;
   SELECT * FROM loans;
   ```
   Алғашқы іске қосқанда 3 автор, 3 оқырман, 4 кітап және 0 беру жазбасы шығады.

**pgAdmin қолдансаңыз:** PostgreSQL сервері → Databases → Create → Database → `library_db`. Содан кейін осы база үшін Query Tool ашып, `database/library_db.sql` файлын орындаңыз. `CREATE DATABASE` командасы pgAdmin арқылы база жасау кезінде қажет емес.

**psql нұсқасы:**
```bash
psql -U postgres -d postgres -f database/01_create_database.sql
psql -U postgres -d library_db -f database/library_db.sql
```
`library_db` бұрын бар болса, бірінші команданы орындамаңыз.

## 2. Java қолданбасын іске қосу

1. IntelliJ IDEA → **Open** → жобаның түбір қалтасын (`Kitaphana_CRUD_Java_PostgreSQL`) таңдаңыз.
2. IntelliJ жобаға Maven ретінде кіргенін тексеріңіз. `pom.xml` ішінде **`org.postgresql:postgresql:42.7.14`** тәуелділігі орнатылған. Интернет болса, Maven оны автоматты жүктейді.
3. Қосылу параметрлері `src/main/java/kz/uib/kitaphana/config/DBConnection.java` ішінде:

   | Параметр | Әдепкі мәні | Түсіндірме |
   |---|---|---|
   | `DB_URL` | `jdbc:postgresql://localhost:5432/library_db` | PostgreSQL JDBC URL |
   | `DB_USER` | `postgres` | PostgreSQL пайдаланушысы |
   | `DB_PASSWORD` | `""` (бос) | Өз құпиясөзіңізді **Environment variables** арқылы беріңіз |

4. IntelliJ IDEA → **Run → Edit Configurations → Main → Environment variables** бөліміне кіріңіз. `DB_PASSWORD` айнымалысына **өз PostgreSQL құпиясөзіңізді** енгізіңіз. Егер пайдаланушы атыңыз басқа болса, `DB_USER` өзгертіңіз; егер сервер басқа мекенжайда болса, `DB_URL` өзгертіңіз. Құпиясөзді кодқа немесе GitHub-қа жарияламаңыз.
5. `src/main/java/kz/uib/kitaphana/Main.java` → **Run 'Main.main()'**. Экранда «PostgreSQL деректер қорына қосылым сәтті орнатылды» және қазақша мәзір ашылуы тиіс.

Maven терминалы арқылы:
```bash
mvn clean compile exec:java
```

**МАҢЫЗДЫ:** Деректер қоры мен кестелерді алдымен жасаңыз. Java бағдарламасы оларды өзі жасамайды, ол бар кестелерге қосылады.

## 3. Деректер қорының моделі

```text
AUTHORS (1) ----< BOOKS (1) ----< LOANS >---- (1) READERS
  id PK             id PK           id PK             id PK
                    author_id FK    book_id FK
                                    reader_id FK
```

| Кесте | Мазмұны мен маңызды өрістер |
|---|---|
| `authors` | `id` (PK), `full_name`, `country` |
| `books` | `id` (PK), `title`, `author_id` (FK), `publication_year`, `isbn` (UNIQUE), `total_copies`, `available_copies` |
| `readers` | `id` (PK), `full_name`, `phone` (UNIQUE) |
| `loans` | `id` (PK), `book_id` (FK), `reader_id` (FK), `loan_date`, `due_date`, `return_date` |

- Негізгі кілттер үшін PostgreSQL-дегі **`GENERATED BY DEFAULT AS IDENTITY`** қолданылған.
- Сыртқы кілттер (**FOREIGN KEY**) байланысты жазбаларды қорғау үшін `ON DELETE RESTRICT` шартын қолданады.
- **CHECK** шектеулері теріс даналар санына және қате күндерге жол бермейді.
- Бастапқы деректерді қайта енгізбеу үшін `INSERT ... ON CONFLICT ... DO NOTHING` қолданылады.
- Кітап беру және қайтару кезінде **транзакциялар** (`commit`/`rollback`) және `SELECT ... FOR UPDATE` қолданылған.

## 4. CRUD операциялары

| Бөлім | Create | Read / іздеу | Update | Delete |
|---|---|---|---|---|
| Авторлар | Автор қосу | Көру, атымен іздеу | Атын/елін өзгерту | Жою |
| Кітаптар | Кітап қосу | Көру, атауымен іздеу | Мәліметтерін/дана санын өзгерту | Жою |
| Оқырмандар | Оқырман қосу | Көру, атымен іздеу | Атын/телефонын өзгерту | Жою |
| Кітап беру | Беру жазбасын қосу | Тізім, оқырман бойынша іздеу | Мерзімін өзгерту және қайтару | Жою |

- Пайдаланушы енгізген мәндер SQL мәтініне жапсырылмайды: **`PreparedStatement`** және `?` параметрлері қолданылады.
- Адам аттарын іздеу PostgreSQL-дің **`ILIKE`** операторы арқылы орындалады (бас/кіші әріпті елемейді).
- Барлық SQL байланыстары `try-with-resources` арқылы жабылады, қателер `SQLException` арқылы өңделеді.
- Мәзір әр операциядан кейін қайта ашылады.

### Кітап беру мысалы

Бірінші кітапта `total_copies=3`, `available_copies=3`.
1. `Кітап беру` бөлімінде `book_id=1`, `reader_id=1`, болашақ күн енгізіңіз.
2. Операция орындалса, `loans` кестесіне жаңа жазба қосылады, `books.available_copies=2` болады.
3. Қайтарған кезде `loans.return_date` толтырылады, `books.available_copies=3` болады.
4. Қолдағы даналар таусылған болса, қосымша кітап берілмейді.
5. Беру тарихы бар кітапты немесе оқырманды жоюға сыртқы кілт шектеуі кедергі жасайды.

## 6. Жиі кездесетін қателер

- **`FATAL: password authentication failed`** — `DB_USER`/`DB_PASSWORD` қате. PostgreSQL құпиясөзін қарап, IntelliJ Run Configuration өзгертіңіз.
- **`Connection refused`** — сервер тоқтап тұр немесе порт (`5432`) дұрыс емес.
- **`FATAL: database "library_db" does not exist`** — деректер қорын жасаңыз және атауын тексеріңіз.
- **`relation "authors" does not exist`** — `library_db.sql` тиісті базаға орындалмаған немесе басқа schema қолданылған.
- **`duplicate key` / `foreign key violation`** — бірегей мән қайталанған немесе байланысқан деректер бар.
- **`No suitable driver`** — Maven тәуелділіктерін қайта жүктеңіз (Reload All Maven Projects).

## 7. Оқытушыға көрсету

`СЫНАҚ_НӘТИЖЕСІ_ҮШІН.md` файлы бойынша CRUD әрекеттерін өз PostgreSQL серверіңізде орындап, нәтижесін және скриншоттарды белгілеңіз. Бұл файл **сынақ нәтижесі емес**, тек тексеру жоспары.

## 8. Бастапқы тапсырмамен айырмашылық

Жобаның функционал талаптары (4 байланысты кесте, JDBC, CRUD, PreparedStatement, DBConnection, Maven, мәзір, қателерді өңдеу) сақталған. Бірақ түпнұсқа тапсырма **MySQL Connector/J** қолдануды міндеттейді. Пайдаланушының өтініші бойынша бұл талап **PostgreSQL + pgJDBC** ретінде өзгертілді.

# «Кітапхана» — PostgreSQL нұсқасын тексеру жоспары

Бұл чек-парақ — бағдарламаны өз компьютеріңізде сынауға арналған **жоспар**. Төмендегі нәтижелер орындалған сынақ ретінде берілмейді.

| № | Әрекет | Күтілетін нәтиже | Тексерілді ме? |
|---|---|---|---|
| 1 | PostgreSQL `library_db` деректер қорына қосылу | Қосылым орнатылды | □ |
| 2 | `SELECT * FROM authors` | 3 бастапқы автор | □ |
| 3 | `SELECT * FROM books` | 4 бастапқы кітап | □ |
| 4 | Авторды қосу / іздеу / өзгерту / жою | Тиісті CRUD орындалады | □ |
| 5 | Кітапты қосу / іздеу / өзгерту / жою | Тиісті CRUD орындалады | □ |
| 6 | Оқырманды қосу / іздеу / өзгерту / жою | Тиісті CRUD орындалады | □ |
| 7 | Кітап беру: `book_id=1`, `reader_id=1` | `loans` жазбасы қосылып, қолдағы дана 3-тен 2-ге кемиді | □ |
| 8 | Кітап беруді іздеу | Оқырманға тиесілі беру көрсетіледі | □ |
| 9 | Берілген кітаптың мерзімін өзгерту | `due_date` жаңарады | □ |
| 10 | Кітапты қайтару | `return_date` толып, қолдағы дана 3-ке көбейеді | □ |
| 11 | Қайтарылған беру жазбасын жою | Беру жазбасы жойылып, дана саны өзгермейді | □ |
| 12 | Бірінші кітапты 3 рет беру және 4-рет беріп көру | Төртінші беру әрекетіне жол берілмейді | □ |
| 13 | Қате `author_id`, қайталанған `isbn` немесе телефон енгізу | SQLException өңделеді, мәзір жұмысын жалғастырады | □ |
| 14 | Барлық мәзірлердегі `0. Артқа`, негізгі мәзірдегі `0. Шығу` | Дұрыс мәзірге қайтады/бағдарламадан шығады | □ |

**Скриншот ұсыныстары:** DataGrip-та `authors` / `readers` / `books` / `loans`, IntelliJ-дегі `pom.xml` және жоба бумалары, CRUD кезінде консоль, кітап беру және қайтарудан кейінгі `available_copies`.

**Ескерту:** 7–12-қадамдардағы `loans.id` мәні әр орнатуда өзгеше болуы мүмкін; нақты ID-ді мәзірден қарап енгізіңіз. Төртінші кітап беру сынағынан кейін берілген кітаптарды қайтарыңыз.

# «КІТАПХАНА» — Java Swing + PostgreSQL CRUD

**Бұл жаңа ойдан шығарылған CRUD емес.** GUI тапсырмасы **сіздің бұрынғы `Kitaphana_CRUD_Java_PostgreSQL` жобасының нақты Java коды мен `library_db.sql` файлының негізінде** орындалды. Алдыңғы төрт DAO, `DBConnection`, `ConsoleMenu`, `Input`, Maven жобасы және бастапқы SQL сақталған.

## 1. Тапсырмадағы талаптардың орындалуы

| Талап | Орындау жолы |
|---|---|
| `JFrame`, `JPanel`, Layout Manager | `gui/Dashboard.java`: негізгі терезе, панельдер, `BorderLayout`, `GridLayout`, `FlowLayout` |
| `JTable` + `TableModel` | 4 бөлімде `DefaultTableModel` және өңдеуге жабық ұяшықтар |
| `JScrollPane` | Әр кестеде тік/көлденең айналдыру жолағы |
| Add / Edit / Delete / Refresh | Әр бөлімнің батырмалары бұрынғы DAO әдістеріне қосылған |
| Add/Edit формалары | `gui/FormDialogs.java`, таңдалған жазбаның өрістері толтырылады |
| Тексеру және қателер | Бос өріс, кітап саны, жыл, ұзындық, күн; SQLState бойынша түсінікті хабар |
| Бірізді интерфейс | `gui/UiTheme.java`: түс, қаріп, аралықтар |
| Қосымша мүмкіндіктер | Іздеу, бағандарды сұрыптау, статистика, 4 бөлім, кітапты қайтару |

## 2. IntelliJ IDEA арқылы іске қосу

1. Осы архивті ашыңыз. IntelliJ IDEA → **File → Open** → осы жобаның **`pom.xml`** файлы бар бумасын таңдаңыз. **Maven** ретінде жүктеңіз.
2. **JDK 17 немесе одан жоғары** орнатыңыз. IDE Maven тәуелділіктерін жүктесін.
3. **Бұрын құрылған `library_db` болса, қайта құрудың қажеті жоқ!** Осы жоба сіздің бастапқы базаңызды пайдаланады.
4. Егер база мүлдем жоқ болса, DataGrip арқылы әдепкі `postgres` деректер қорында **`database/01_create_database.sql`**, содан кейін жаңадан жасалған `library_db` ішінде **`database/library_db.sql`** орындаңыз.
5. PostgreSQL қосылым деректерін IntelliJ IDEA → **Run → Edit Configurations → Environment variables** аймағына қосыңыз:

   | Айнымалы | Мысал |
   |---|---|
   | `DB_URL` | `jdbc:postgresql://localhost:5432/library_db` |
   | `DB_USER` | `postgres` |
   | `DB_PASSWORD` | сіздің нақты PostgreSQL пароліңіз |

   **Назар аударыңыз:** бұл мәндерді кодқа енгізбеңіз. Егер PostgreSQL университет серверінде тұрса, `localhost` орнына тек сізге рұқсат етілген сервердің адресін пайдаланыңыз. DataGrip қосылып тұрғаны Java бағдарламасы да сол серверге қосылады дегенді білдірмейді.
6. `src/main/java/kz/uib/kitaphana/Main.java` ашып, жасыл **Run** батырмасын басыңыз. Бұл файл енді графикалық терезені ашады. **Міндетті түрде графикалық жұмыс үстелі бар ортада** іске қосыңыз (серверде display жоқ болса, `JFrame` ашылмайды).
7. Базаға қосылым дұрыс болса, **Кітаптар, Авторлар, Оқырмандар, Кітап беру** бөлімдерінде нақты жазбалар көрсетіледі.

**Терминал арқылы:** `mvn clean compile exec:java` (Maven орнатылған болса).

### Бұрынғы консольдік нұсқа да сақталды

Бастапқы `Main.java`-дағы іске қосу логикасы өзгеріссіз **`ConsoleMain.java`** файлына көшірілді. Консольді көрсету керек болса, IntelliJ-де `kz.uib.kitaphana.ConsoleMain.main()` іске қосыңыз.

## 3. GUI қалай жұмыс істейді

- **Кітаптар:** атауы, авторы, шыққан жылы, ISBN, жалпы және бос дана саны; авторды ашылмалы тізімнен таңдауға болады.
- **Авторлар:** аты-жөні, елі.
- **Оқырмандар:** аты-жөні, телефон (бірегей).
- **Кітап беру:** тек қолда бар кітаптар, оқырман және қайтару мерзімін таңдау; **«Қайтару»** батырмасы қор санын қалпына келтіреді.
- **Add (Қосу):** мәндер тексеріліп, бұрынғы `DAO.create(...)` шақырылады.
- **Edit (Өзгерту):** таңдалған жазбаның мәндері формаға толтырылады, бұрынғы `DAO.update(...)` шақырылады (беруде `updateDueDate`).
- **Delete (Жою):** растаудан кейін бұрынғы `DAO.delete(...)` шақырылады.
- **Refresh (Жаңарту):** `DAO.list()` әдістері PostgreSQL жазбаларын қайта оқиды; сұраныстар `SwingWorker` арқылы орындалады, сондықтан терезе қатып қалмайды.
- **Іздеу/сұрыптау:** `TableRowSorter` бойынша жергілікті сүзгі және баған тақырыптарын басу.

**Маңызды:** кітап саны мен қайтару логикасы GUI ішіндегі тікелей SQL арқылы емес, **бұрынғы `BookDAO` және `LoanDAO` транзакциялары** арқылы өзгереді. Жаңа деректер қоры немесе жаңа `CREATE TABLE` логикасы жасалмады.

## 4. Қандай файлдар өзгерді

**Бұрынғы файлдар:**
- `config/DBConnection.java` — **өзгерген жоқ**; сол `DB_URL`, `DB_USER`, `DB_PASSWORD` қолданылады.
- `database/01_create_database.sql` және `database/library_db.sql` — **өзгерген жоқ**.
- `dao/{AuthorDAO,ReaderDAO,BookDAO,LoanDAO}.java` — ескі CRUD SQL және транзакциялар сақталған; кестеге дерек беретін `list()`/record моделі қосылды; өңдеу/жою сияқты әдістер `boolean` қайтарады (UI операция сәтті өткенін білу үшін). Бұрынғы консоль мәзірі бұл әдістерді бұрынғыша шақыра алады.
- `Main.java` — GUI іске қосады; ескі нұсқасы `ConsoleMain.java` ретінде сақталған.

**Жаңа файлдар:**
- `gui/GuiMain.java` — Swing EDT іске қосу.
- `gui/Dashboard.java` — терезе, кестелер, батырмалар, статистика, `SwingWorker`.
- `gui/FormDialogs.java` — Add/Edit формалары, тексеру.
- `gui/UiTheme.java` — интерфейс стилі.

Бұрынғы толық нұсқаулық `README_CRUD_ORIGINAL.md` ішінде. Тексеру жоспары `GUI_TEST_CHECKLIST.md` ішінде.

## 5. Ескерту / тексеру шегі

Жоба **Java 17 синтаксисімен компиляциядан өткізілді** және Swing терезесінің құрылымы виртуалды дисплейде тексерілді. **Нақты `library_db` серверіне қосылу және толық end-to-end CRUD операциялары осы ортада тексерілмеді** — серверге рұқсат жоқ. Сынақ нәтижелерін өзіңіз орындағаннан кейін `GUI_TEST_CHECKLIST.md` ішіне белгілей аласыз.

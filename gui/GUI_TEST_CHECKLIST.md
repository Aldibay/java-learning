# JAVA SWING GUI — ТЕКСЕРУ ЖОСПАРЫ

**Мұндағы нәтижелер алдын ала «өтті» деп белгіленбеген.** Нақты PostgreSQL серверінде бағдарламаны іске қосып тексеріңіз.

| № | Әрекет | Күтілетін нәтиже | Орындалды |
|---|---|---|---|
| 1 | `Main` іске қосу | `JFrame` терезесі ашылады | ☐ |
| 2 | `library_db` базасына қосылу | Төрт бөлімде нақты деректер шығады | ☐ |
| 3 | `authors` — Add | Жаңа автор деректер қорына сақталады | ☐ |
| 4 | `authors` — Edit | Тізімнен таңдалған автордың өрістері алдын ала толтырылған | ☐ |
| 5 | `authors` — Delete | Растаудан кейін автор жойылады | ☐ |
| 6 | `readers` — Add/Edit/Delete | Өзгерістер базаға жазылады | ☐ |
| 7 | `books` — Add | Автор тізімінен таңдалып, кітап қосылады | ☐ |
| 8 | `books` — Edit | Кітаптың бар данасы, жыл, ISBN түзетіледі | ☐ |
| 9 | `books` — Delete | Байланысқан беру болса, FK қатесі түсінікті көрсетіледі | ☐ |
| 10 | `loans` — Add | Қордағы `available_copies` 1-ге азаяды | ☐ |
| 11 | `loans` — Edit | Қайтару мерзімі өзгереді | ☐ |
| 12 | `loans` — Қайтару | Қайтару күні толтырылады, бос дана саны 1-ге өседі | ☐ |
| 13 | `loans` — Delete | Белсенді жазба жойылса, кітап қоры қалпына келеді | ☐ |
| 14 | Кез келген бөлімде Refresh | PostgreSQL-ден жаңадан оқиды | ☐ |
| 15 | Іздеу және бағандарды сұрыптау | Сүзгі мен сұрыптау жұмыс істейді | ☐ |
| 16 | Ешбір жол таңдамай Edit/Delete басу | Батырмалар белсенді емес | ☐ |
| 17 | Міндетті өрісті бос қалдыру | Түсінікті ескерту шығады | ☐ |
| 18 | Сандық және күндік қате мән | Жазба сақталмайды, қате түсіндіріледі | ☐ |
| 19 | ISBN/телефон қайталануын сынау | `UNIQUE` қатесі түсінікті көрсетіледі | ☐ |
| 20 | Жалған PostgreSQL паролі | Қосылым қатесі көрсетіледі, бағдарлама жабылып қалмайды | ☐ |
| 21 | Ескі консоль: `ConsoleMain` | Бұрынғы мәзір арқылы CRUD жұмыс істейді | ☐ |
